# realestate-analyzer

아파트 실거래가 기반 **1페이지 간략 분석** 웹앱 (Next.js 16, 사파리/모바일 대응).

- **매매**: 시/도 → 구 선택 + 아파트명 입력 → 단지 선택 → 1페이지 리포트
  - 평형대별(상위 2개) 매매·전세 월평균 실거래 차트 + 상승시작/전고점/하락점/현재 표시
  - 핵심 수치: 현재가, 전고점, 전세가율, 투자금(갭), 기회구간(전고점 대비)
  - 시나리오 분석(전고점 회복 시 차익·투자금 대비 수익률), 거래 활성도, 특징 태그, 가치/가격/투자생각 코멘트
  - 인쇄 / PDF 저장(가로 A4 한 장)
- **분양**: 시/도·구별 청약홈 APT 분양공고(최근 12개월·예정), 상태(청약예정/접수중/발표대기/계약/완료)
  - 단지 상세: 청약 일정, 규제(분양가상한제·투기과열 등), 주택형별 분양가·공급세대·1순위 경쟁률·당첨가점
  - **안전마진**: 같은 구 최근 12개월 실거래 중 입주 5년(부족하면 10년) 이내·전용 ±5㎡ 신축 중위가격 − 분양가(최고)

## 실행

```bash
npm install
cp .env.example .env.local   # DATA_GO_KR_KEY 입력
npm run dev
```

키가 하나도 없으면 **데모(가상) 데이터**로 동작합니다. 키는 있는 것만 켜지고, 없는 항목은 "준비 중"으로 표시됩니다. 홈 화면 하단에 연결 상태가 나옵니다.

### 환경변수

| 변수 | 용도 |
| --- | --- |
| `DATA_GO_KR_KEY` | 공공데이터포털 인증키 (아래 API별로 활용신청) |
| `VWORLD_API_KEY` | VWorld 배경지도 + 지번주소 → 좌표. 키 신청 시 서비스 URL에 배포 도메인·localhost 등록 |
| `VWORLD_DOMAIN` | (선택) VWorld 키에 등록한 도메인 |
| `KAKAO_REST_API_KEY` | 카카오 로컬: 반경 1km 학교·역·마트·병원·학원·공원 검색, 좌표 보조 |

공공데이터포털 활용신청 목록 (인증키 하나로 공용):
- 국토교통부_아파트 매매 실거래가 상세 자료 (`RTMSDataSvcAptTradeDev`) - 필수
- 국토교통부_아파트 전월세 실거래가 자료 (`RTMSDataSvcAptRent`) - 필수
- 국토교통부_공동주택 단지 목록제공 서비스 (`AptListService4`) - 세대수 등 연동에 필요
- 국토교통부_공동주택 기본 정보제공 서비스 (`AptBasisInfoServiceV5`) - 세대수·동수·사용승인일·복도유형·최고층·시공사
- (기본 정보제공 서비스에 포함된 상세조회 `getAphusDtlInfoV5`) - 주차대수·지하철 도보시간 (선택)
- 국토교통부_건축HUB_건축물대장정보 서비스 (`BldRgstHubService`) - 건폐율·용적률 (선택)
- 한국부동산원_청약홈 분양정보 조회 서비스 (`ApplyhomeInfoDetailSvc`, api.odcloud.kr) - 분양 탭
- 한국부동산원_청약홈 청약접수 경쟁률 및 특별공급 신청현황 조회 서비스 (`ApplyhomeInfoCmpetRtSvc`) - 경쟁률·당첨가점

> K-apt·건축물대장 엔드포인트/필드명은 `src/lib/kapt.ts` 상단 상수에 모여 있습니다. 실제 키로 첫 호출 시 응답을 확인해 필요하면 이 부분만 조정합니다.

## 분석 기준
- 기본 최근 24개월(이번 달 포함), 차트에 표시되는 평형 중 하나라도 매매가 12건 미만이면 36개월로 자동 확장 (리포트에서 자동/24/36개월 선택 가능). 해제 거래 제외
- 평형대: 전용 40㎡ 미만 10평대 / 62㎡ 미만 20평대 / 100㎡ 미만 30평대 / 135㎡ 미만 40평대 …
- 월평균은 평형대 내 대표 전용면적 기준 ㎡당 가격으로 환산(74㎡·84㎡ 혼재 왜곡 방지)
- 전세 = 월세 0원 거래, 최근 전세가는 마지막 전세 거래월 기준 3개월 평균
- 전고점 = 기간 내 최고 월평균, 하락점 = 전고점 이후 최저, 상승시작 = 전고점 이전 최저(5% 이상 상승 시)

## 배포 (사파리에서 사용)
Vercel에 저장소를 연결하고 환경변수 `DATA_GO_KR_KEY`를 설정하면 됩니다. 아이폰 사파리에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 부가정보 동작 방식
- **K-apt 매칭**: 시군구 단지목록에서 법정동 + 단지명 유사도(2-gram)로 가장 비슷한 단지 선택 (기준 미달이면 "정보 없음")
- **건축물대장**: K-apt 법정동코드(10자리) + 실거래 지번으로 총괄표제부 조회
- **좌표**: VWorld 지오코더(지번→도로명) → 실패 시 카카오 주소검색
- **환경 등급**: 역 거리, 대형마트, 병원 수, 공원 (9점 만점 → S/A/B/C)
- **학군 등급**: 초등학교 거리, 중·고 수, 학원 수 (9점 만점 → S/A/B/C)
- 부가정보 조회 실패는 리포트 전체를 막지 않고 해당 칸에만 사유 표시

- **공급 등급**: 같은 구 청약홈 APT 분양공고(최근 4년) 중 입주예정월이 향후 3년 이내인 단지의 공급규모 합 → 연평균 500 미만 S / 1,500 미만 A / 3,000 미만 B / 이상 C
  (공급규모는 분양분 기준이라 정비사업 조합원분은 빠질 수 있음, 오피스텔·임대 제외)
