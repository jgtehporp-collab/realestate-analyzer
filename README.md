# realestate-analyzer

아파트 실거래가 기반 **1페이지 간략 분석** 웹앱 (Next.js 16, 사파리/모바일 대응).

- **매매**: 시/도 → 구 선택 + 아파트명 입력 → 단지 선택 → 1페이지 리포트
  - 평형대별(상위 2개) 매매·전세 월평균 실거래 차트 + 상승시작/전고점/하락점/현재 표시
  - 핵심 수치: 현재가, 전고점, 전세가율, 투자금(갭), 기회구간(전고점 대비)
  - 시나리오 분석(전고점 회복 시 차익·투자금 대비 수익률), 거래 활성도, 특징 태그, 가치/가격/투자생각 코멘트
  - 인쇄 / PDF 저장(가로 A4 한 장)
- **분양**: 준비 중

## 실행

```bash
npm install
cp .env.example .env.local   # DATA_GO_KR_KEY 입력
npm run dev
```

`DATA_GO_KR_KEY`가 없으면 **데모(가상) 데이터**로 동작합니다.

### API 키
공공데이터포털(data.go.kr)에서 아래 두 API를 활용신청하고 같은 일반 인증키를 `DATA_GO_KR_KEY`에 넣습니다.
- 국토교통부_아파트 매매 실거래가 상세 자료 (`RTMSDataSvcAptTradeDev`)
- 국토교통부_아파트 전월세 실거래가 자료 (`RTMSDataSvcAptRent`)

## 분석 기준
- 최근 24개월(이번 달 포함) 거래, 해제 거래 제외
- 평형대: 전용 40㎡ 미만 10평대 / 62㎡ 미만 20평대 / 100㎡ 미만 30평대 / 135㎡ 미만 40평대 …
- 월평균은 평형대 내 대표 전용면적 기준 ㎡당 가격으로 환산(74㎡·84㎡ 혼재 왜곡 방지)
- 전세 = 월세 0원 거래, 최근 전세가는 마지막 전세 거래월 기준 3개월 평균
- 전고점 = 기간 내 최고 월평균, 하락점 = 전고점 이후 최저, 상승시작 = 전고점 이전 최저(5% 이상 상승 시)

## 배포 (사파리에서 사용)
Vercel에 저장소를 연결하고 환경변수 `DATA_GO_KR_KEY`를 설정하면 됩니다. 아이폰 사파리에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.
